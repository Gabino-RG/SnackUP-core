# Documentación de SnackUP

La aplicación Flutter y su configuración de Firebase se encuentran en `../app/`.
El `README.md` existente del repositorio se conserva en la raíz.

Desde la raíz, ejecuta:

```bash
cd app
flutter pub get
flutter run
```

Ejecuta también `flutterfire configure`, `flutter build web` y `firebase deploy`
desde `app/`, para conservar las rutas relativas de Firebase y de los recursos.
Abre `app/` en el editor si quieres usar la configuración de `.vscode` trasladada.
