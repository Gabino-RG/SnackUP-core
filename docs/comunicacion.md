# Comunicación del proyecto

Usa un issue para registrar errores o proponer mejoras con las plantillas del
repositorio. Incluye los pasos para reproducir, el entorno y los criterios de
aceptación que permitan revisar el resultado.

Vincula el issue en el pull request y describe los cambios y su validación.
Mantén las decisiones de implementación y los pendientes en esa conversación
para que el equipo pueda consultarlos.

Los comandos de Flutter y Firebase se ejecutan desde `app/`. Indica en el pull
request qué comandos ejecutaste, cuáles fallaron y cuáles no pudiste ejecutar.

No subas credenciales, archivos de configuración locales ni datos personales
en capturas o registros.
