# Implementación anterior con Firebase

Estos archivos `.dart.txt` conservan como referencia la implementación previa y sus pruebas. No se compilan ni ejecutan. El cliente activo está en `lib/api` y `lib/student_api` y utiliza la API V3 de FastAPI.

No se ejecutó ninguna migración, publicación de reglas ni modificación de datos en Firebase. Los archivos originales de configuración y reglas de Firebase en la raíz no se usan en el flujo REST y se mantienen sin cambios en esta integración.
